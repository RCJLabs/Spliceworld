# data/voice-pools.json

R109 — the spare phrasings, and the only file in `/data` that is not about one system. Pooling the voice took 67 distinct phrasings to 411 and put 29 KB in front of the first paint; this is where the 29 KB went. The FIRST line of every pool still ships in the file that owns it — `news.json`, `philosophies.json`, `operations.json`, `regions.json`, `resequencer.json` — so the wire, the ticker and the player's own voice all work before this lands. The VARIANTS ride here, fetched in R81's second round beside the geometry: before it arrives the game says what it said last milestone, after it the pools rotate, and no line is ever lost. It is R81's split applied to words instead of shapes.

Keyed by the PATH into the indexed content, not by pool family — `news.spar_done.lines`, `philosophies.improver.monologue.capture`, `ticker`. The first draft hand-listed the six families it knew about, which made a seventh an engine edit, and CLAUDE.md says content must never need one. `attachVoicePools` in render/renderer.js walks each path, appends, and skips any path the tree no longer has, so retiring an event here is a deletion rather than a migration. A Node tool reads every file off disk and gets the merge in `indexContent`, which is why the harness scores the voice the player actually hears. Adding phrasings is a key here and nothing else; the voice block in tools/smoke.js holds the other end — every authored line must be reachable from a live emitter, and no phrasing may be more than 5% of what a 180-day campaign says.
