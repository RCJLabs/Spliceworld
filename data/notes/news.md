# data/news.json

R62 — the news wire's copy. Every sentence the wire prints lives here, keyed by EVENT id; engine modules emit {event, params} and never a sentence. Before this file, 17 player-facing lines were written inside campaign.js and rehab.js, so a new world-reaction was an engine edit — against CLAUDE.md's 'all content is data'. `lines` is the pool for an event. R109 — a CURSOR walks it rather than a roll picking from it: `state.wireAt` holds the next index per event and every telling advances it, so a pool of five is heard five times before any line is heard twice, the seed decides only where a save OPENS each pool, and a reload mid-run replays the wire rather than rerolling it. The variants themselves live in `voice-pools.json` and arrive after the first paint; the line kept here is the one the wire uses until they do. `by` is an optional per-philosophy pool, checked first, which is how the world reacts differently to a Naturalist than to an Engineer — the same machinery R10 built for the rivals, pointed at the campaign instead. Placeholders are {braces} filled by campaign/monologue.js `fill`, which leaves an unknown key ALONE rather than printing 'undefined', so a typo reads oddly instead of breaking. Adding a reaction is a key here plus one emit at the site of the event; it must never be an engine change again. The gate in tools/smoke.js runs the invariant both ways: every event emitted in code has copy here, and every event here has an emitter — R20's rule, pointed at the wire.
